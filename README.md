# Gel Labeler

A lightweight browser-based tool for labelling gel images and exporting clean annotated figures.

The app runs entirely in the browser: load a gel image, crop/adjust it, mark lane positions, add lane labels and ladder labels, then export the final figure as PNG or SVG.

## How to use

1. Open the web page.
2. Drag and drop a gel image, or click to browse.
3. Optionally crop the image.
4. Adjust brightness, contrast, or invert colours if needed.
5. Set the number of lanes.
6. Click the centre of the first lane.
7. Click the centre of the last lane.
8. Add lane labels in the side panel.
9. Optionally add a DNA/protein ladder and drag the ladder labels into position.
10. Export the final figure as PNG or SVG.
